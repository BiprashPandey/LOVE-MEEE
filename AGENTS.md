# AGENTS.md

## Project Context

This is the **LOVE MEEE** productivity and motivation app repository.

## Key Files

- `src/`: frontend application source.
- `src/api/storageClient.js`: local storage client for offline entity management.
- `src/lib/AppContext.jsx`: React context for state management.
- `src/lib/NotificationService.js`: Web Notifications & audio/haptic synthesis engine.
- `vite.config.js`: Vite configuration with path aliases.

## Local Commands

- `npm run dev`: Start local development server.
- `npm run build`: Build production bundle.
- `npm run lint`: Run ESLint checks.
